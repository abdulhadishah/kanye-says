# 🎤 Kanye Says...

A simple desktop application built using Python Tkinter that fetches and displays random Kanye West quotes from a public API.

## ✨ Technologies

- `Python`
- `Tkinter`
- `Requests`
- `API`
- `JSON`

## 🚀 Features

- Fetches a random quote on each button click
- Simple graphical interface using Tkinter
- Uses a public REST API endpoint
- Displays dynamic text inside the UI

## 📍 The Process

This project was built as **Day 33 of the 100 Days of Python Code** course to understand how APIs work and how to interact with them in Python.

The focus was on learning what an API endpoint is, how to make HTTP requests using the `requests` library, and how to work with JSON responses. Each time the user clicks the button, a request is sent to the API endpoint, a JSON response is received, and a random quote is extracted and displayed in the interface.

This project also reinforced combining external data with a Tkinter-based GUI to create interactive applications.

## 🚦 Running the Project

1. Clone the repository  
2. Install dependencies: `pip install requests`  
3. Ensure the image files are present in the project folder  
4. Run the script: `python main.py`  
5. Click the Kanye icon to fetch a new quote
